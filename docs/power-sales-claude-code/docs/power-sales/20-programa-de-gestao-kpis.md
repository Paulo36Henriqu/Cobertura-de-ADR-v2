PROGRAMA DE GESTÃO POWER SALES
Introdução e Objetivos
Dados os Atributos retratados no Manual de Operações Power Sales, é necessário
garantir uma forma de gestão de desempenho de cada um deles, isto é, qual o grau de
desenvolvimento de cada Atributo em cada grupo concessionário. Para isso foi
estruturado o Programa de Gestão Power Sales.

PROGRAMA DE GESTÃO

O objetivo do Programa de Gestão Power Sales é:
Construir um modelo de avaliação para cada atributo por meio de
indicadores a fim de medir o grau de maturidade, evolução e
desenvolvimento de cada grupo concessionário nos 16 atributos.
O modelo de avaliação atribui uma nota para cada atributo e cada pilar
para depois fazer uma consolidação geral, com o intuito de chegar a uma
nota final do grupo concessionário no Programa de Gestão Power Sales.

ATRIBUTO: Preparação Comercial (8)

KPI GERENCIAMENTO

Métrica

Preparação Comercial:
A equipe comercial da loja realiza preparação mensal e
semanal de acordo com as diretrizes do Power Sales
(ou seja, análise de performance, novas oportunidades,
funil de vendas, plano de visitas, etc..).Em visão
evolutiva, este KPI Gerencial é a somatória das lojas
do Grupo Concessionário.

Preparação Mensal: Os CENs possuem um momento
individual no início de cada mês para realizar a própria
avaliação de performance do mês anterior e planejar
objetivos para o mês seguinte.
Performance: Os CENs analisam seus resultados
individuais de vendas de máquinas do mês anterior,
identificam gaps de vendas e definem objetivos de
vendas de máquinas para próximo mês.

KPI SUPORTE

Novas oportunidades:
Os CENs analisam indicadores como horímetro,
idade do parque de máquinas, investimento em
manutenção, alertas CSC para identificarem novas
oportunidades na carteira de clientes.
Funil de vendas: Os CENs analisam o próprio funil de
vendas, a fim de entender o foco e objetivos que
necessita garantir no próximo mês.

Plano de visitas:
Os CENs realizam a preparação semanal e mensal com
os clientes prioritários a serem visitados no mês
seguinte, com as variáveis: oportunidade já abertas,
novas oportunidades identificadas e frequência ideal
de visita de cada tipo de cliente.

Alinhamento: A preparação mensal realizada
individualmente por cada CEN é alinhado e validado
com o Gerente / Supervisor de Vendas.
Atualização do CRM: Os CENs garante atualização do
CRM com base na preparação comercial mensal e
semanal, refletindo o plano de visitas e criação das
oportunidades identificadas.

2.1. ACESSAR O RELATÓRIO RAIO X DA CARTEIRA DE CLIENTES
• Esse relatório se chama RAIO X da carteira porque o CEN consegue analisar alguns
indicadores por tipo de máquina e por modelo, identificando possíveis
oportunidades. É necessário o CEN identificar oportunidades não somente para venda
de máquinas, mas também conectividade.
• Idealmente, esse relatório deverá estar no CRM, construído de forma automática a
partir das informações atualizadas (parque de máquinas do cliente, horímetro das
máquinas, histórico de serviços etc..).

O QUE É O FUNIL “NECESSÁRIO”?
É uma forma de estimar a quantidade de oportunidades necessárias para conseguir
atingir a meta definida, a partir das taxas de conversão histórica de cada estágio do funil
de vendas.

visão para cada tipo de máquina. Para isso, o CEN deve:
1. Pelo CRM, identificar as taxas de conversão média para cada tipo de máquina
para cada estágio do funil;
2. Pegar a meta mensal definida para cada tipo de máquina para o mês seguinte;
3. Calcular a quantidade de oportunidades que são necessárias em cada estágio
para atingir a meta de cada tipo de máquina (a seguir um exemplo prático de

Para que serve?

•

Alinhamento de papéis e responsabilidades da equipe comercial dado
um ambiente no qual envolve várias soluções.

•

Definição clara da necessidade do suporte de especialistas à equipe
comercial referente à outras áreas do grupo concessionário.

Por meio deste modelo é possível ter visibilidade da equipe de especialistas
adequada para realizar o atendimento dos diferentes segmentos de clientes
dada a proposta de valor definida.

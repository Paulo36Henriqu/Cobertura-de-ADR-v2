# Como usar no Claude Code

1. Copie para a raiz do seu projeto:
   - a pasta `.claude/` (contém a skill power-sales)
   - a pasta `docs/power-sales/`
   - o conteúdo de `CLAUDE.md` (se o projeto já tiver um, cole este bloco no final)
2. Abra o Claude Code na pasta do projeto. A skill carrega sozinha quando o assunto
   for Power Sales; você também pode chamar com /power-sales.
3. Para usar em todos os projetos, copie `.claude/skills/power-sales/` para
   `~/.claude/skills/power-sales/` e mantenha `docs/power-sales/` em um caminho fixo,
   ajustando o caminho citado no SKILL.md.
